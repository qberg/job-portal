## Component authoring — ADR-0038 (use the `tribune-component` skill)

- **Two gates before CSS.** Gate 1 = API proposal (base-ui primitive + 2-3 surveyed ref APIs + prop/variant axes + compound-vs-flat). Gate 2 = token map (variant×state grid, every cell `component→semantic→primitive→value`, tagged ✅figma/⚠️extrapolated/❌missing, + motion row). Human approves each. Never eyeball a design value (Figma=HITL).
- **3-tier tokens**: primitive(`--color-*`, only tier with literals) → semantic(`--tbn-*`, per-component `@layer base { :root,[data-theme=light] }` block, mandatory for any color) → local(`--<cmp>-*`, JIT — only if stateful/multi-variant remap). NO raw `oklch`/hex in component rules — lint-enforced (`check:tokens`).
- **Alias every token (button.css, NOT card.css).** A component's rules reference ONLY its own `--tbn-<cmp>-*` (or local `--<cmp>-*`) — never a foreign `--tbn-*` raw. Re-alias each system token in the component `@layer base` block (`--tbn-dropzone-surface: var(--tbn-bg-surface)`). `card.css` (raw `var(--tbn-bg-surface)` in rules) = legacy shape; ~36/38 still do this. **Convert a component to the alias pattern whenever you touch it** (incremental migration, ADR-0038 §2). Not yet `check:tokens`-gated; review-enforced. When the skill names an exemplar, read THAT file's CSS first — don't anchor on the simplest sibling.
- **`@apply` static utilities** (flex/gap/padding/size/sr-only); raw property ONLY for `var()`-backed decls / transitions / rings. `check:tokens` blocks **dup-token-key** (same prop redefined in one block).
- **Extrapolated values** = `/* @extrapolated(state): reason, pending HITL */` on the token def. `grep @extrapolated` = the un-blessed backlog. Never silently assume a token.
- **cva** iff ≥1 multi-value variant axis (recipe: variant→className→CSS); else `cn()`. **Runtime state** (open/checked/disabled/selected) via base-ui **data-attrs** (`[data-disabled]`), never a minted className.
- **Compound** (`Object.assign`) iff ≥2 consumer-arranged parts; flat for leaf. Children over `renderX`; no mode-swapping booleans.
- **CSS**: `@apply` static utilities; raw property only for `var()`-backed / transitions / rings.
- Run `pnpm -F @jp/tribune check:tokens` before done. Adoption status ledger lives in ADR-0038.
- Styles: Tailwind v4 + CSS tokens. `src/styles/index.css` fixes load order: fontsource → tailwind → `tokens/` → `semantic/` → `base.css` → `utilities.css`.
- **Tailwind v4 PRUNES plain `@theme` vars with no scanned utility usage** — raw `var(--token)` in component CSS is invisible to the scanner, the var resolves EMPTY at runtime, and any `animation:`/`transition:`/`box-shadow:` shorthand consuming it silently collapses to `none` (no build error; killed all motion tokens + popup shadows + `--font-tamil` until 2026-07-07). Token blocks consumed only via `var()` MUST be `@theme static` (motion/radius/shadows/typography now are). `semantic/*.css` `:root` blocks = plain CSS, unaffected.
- Two style entries (one per document): `@jp/tribune/styles` = admin surface (Public Sans, `heading-*`/`label-*`, the global `@theme` default) · `@jp/tribune/styles/public` (+ `/app` combined) = editorial (`bg-text-*`/`title-*`/`ui-*`/`caption-*`, ADR-0027 html-zoom under `html[data-surface="public"]`). Surface = which entry + whether `<html>` carries `data-surface="public"`. `--text-caption-1` diverges across surfaces as 3 sub-props (size/lh/ls), not 1. Hosting both in one app = separate route-group root layouts (ADR-0040), NOT token coexistence.
- Fonts self-hosted via fontsource. Variable = `@fontsource-variable/<x>` (1 file, all weights); static = `@fontsource/<x>` (per-weight). Import lean: variable `…/wght.css` (latin), static `…/latin-700.css` (single weight). Verify subset paths exist: `npm pack <pkg> && tar tzf *.tgz | grep css`.
- Font tokens (`tokens/typography.css` @theme): `--font-sans` (Public Sans, html default), `--font-serif` (PT Serif), `--font-mono`, `--font-tamil`. `:lang(ta)` swaps `--font-sans` → Noto Tamil. PT Serif ships ONLY 400/700 (no 600).
- **web-public marketing type system** (`tokens/typography-public.css` + `components/site-typography/*`, applies ONLY under `[data-surface="public"]`): **composite tokens** — each role owns 4 sub-vars `--text-<x>{,--line-height,--letter-spacing,--font-family}`; the `.tbn-type--<x>` class reads all four. **Role owns the font, no consumer `family` prop** (the industry pattern — like Material/Figma text styles). Face mapping is @extrapolated (Inter Display / PT Serif placeholders) until job-portal's public Figma blesses its display/editorial faces — petition's Sagite/Sheftira were NOT carried. **Language = theming axis** via `[data-surface="public"]:lang(ta)` (specificity 0,2,0 > 0,1,0) repointing size/ls/font-family; ta face = **Ila Sundaram** (CDAC GIST Unicode, self-hosted `fonts/ila-sundaram-08.woff2`; both `--font-ta-display` + `--font-ta-body` point to it, Noto Tamil fallback). Single-weight → no bold overrides in the `:lang(ta)` block (ADR-0071). Legacy Bamini was ASCII glyph-hack (no Unicode cmap) — never ship it. Fluid = `clamp(v390, calc, v1280)` per token PER LANGUAGE (separate ta clamp block from ta Figma anchors); ≥1280 root-zoom is language-agnostic (all rem). `letter-spacing` = **em (figmaPx ÷ fontSizePx)** so it scales at every breakpoint — NOT px/16-as-em (that's ~15× too wide). `SiteHeading` = bg-text-1/2/3 + title-1..6; `SiteText` = ui-1/2/3 + caption-1 (`prose-*`/`ui-heading` DELETED). Marketing/portal callsites are throwaway — DS stays correct, don't chase consumer `family=` breakage.
- **Biscript ink alignment (ADR-0077) — icons/labels center on INK, never line boxes.** Tamil (Ila) ink rides ~0.11em below the Latin-strut box center; `items-center` alone mis-sits every icon-beside-ta-text. Tokens: `--tbn-ink-shift` (0 default; 0.11em set where the Ila face is chosen — typography-public.css + portal.css `:lang(ta)`) consumed via CSS `translate` (composes with transform anims) in every icon slot (button/badge/chip/select/input-group/breadcrumb) + Button's `.tbn-button__content` label slot (lifts ensemble; icon-only variant zeroes both); `--tbn-icon-anchor` (.36em Latin / .2em ta) for standalone icons = container `items-baseline` + `translateY(calc(50% - var(--tbn-icon-anchor)))`. LAWS: new icon-composing component routes its icon through an ink-shift slot; icons = sized SVG, NEVER font chars (`▾▶✕` — per-font glyph boxes); `self-baseline` on the icon alone is a trap (baseline-groups against itself — container takes `items-baseline`); `@font-face` ascent-override can't fix any of this (Latin strut dominates mixed lines) — don't retry it. Alignment bugs: MEASURE (canvas `actualBoundingBox*` + inline baseline marker, methodology in the ADR) before fixing.
- **Public faces self-hosted (NOT fontsource)** — licensed TTFs → `styles/fonts/*.woff2` (`woff2_compress <f>.ttf`), `@font-face` in `styles/fonts/fonts-public.css` imported by `public.css`+`app.css` (and directly by public stories, since SB global = admin `index.css`). Inter Display = 9 static weight faces (browser fetches a weight ONLY when rendered → declaring all 9 is free). Source `*.ttf`/`*.otf` gitignored, only `*.woff2` committed.
- Component `.tsx` MUST `import "./<name>.css"`. JIT bundles CSS only via component own import. Un-imported `.css` = dead. Silent: no styles, no error.
- Raw component CSS: use `var(--tbn-*)` (real semantic props, `semantic/*.css`). NEVER `var(--color-tbn-*)` — those `@theme inline` aliases, feed `bg-/text-/border-tbn-*` utilities only, NOT emitted as runtime props → `var()` = undefined → no color.
- react-resizable-panels v4: `Group`/`Panel`/`Separator`/`usePanelRef`; `onResize` → `{asPercentage, inPixels}`; numeric size prop = px, string = %. ResizeObserver streams EVERY animated-flex frame — never derive a settled width from the last `>0` frame (gate on FSM state / `>=minSize`). Panel paints `flex-basis: defaultSize` pre-registration then swaps to computed `flex: N 1 0px` — a CSS `transition: flex` on panels MUST gate on the app-shell `data-settled` pattern (armed per-panel one rAF after first onResize) or every mount animates a width bulge; a `defaultSize` below `minSize` makes the layout validator steal the deficit from the FIRST panel (it zeroed the sidebar), and `expand()` = `expandToSize ?? minSize` (mount-collapsed panel has no memory — seed via `resize()`). Panel puts `className` on an INNER div — the flex item is the outer `[data-panel]`, so width-affecting CSS must target `[data-slot=…]`, never the slot class (a `.tbn-app-shell__peek` width rule silently no-ops). Peek exit choreography = app-shell.css `:has(.tbn-peek-frame[data-state="closing"])` block (peek grow→0, sidebar pinned to `--tbn-sidebar-w` on the viewport). OPEN DEFECT: mounting/unmounting a Panel rebuilds the group layout from `defaultSize`s — peek open pops a collapsed sidebar to 18% and the machine persists the phantom expand.
- Icons: `pnpm gen:icons` — drop `src/icons/raw/<name>.svg` (16×16, stroke hex, `fill="none"`; svgo → `currentColor`) → `<Name>Icon`. NO package.json entry needed — icons resolve via the glob `"./icons/*"`. Generator camelCases SVG attrs (`stroke-width`→`strokeWidth`, skips `data-`/`aria-`) — raw kebab breaks JSX (`Invalid DOM property`). Never hand-edit `generated/`; regenerate.
- Tests = Storybook `play` stories only (no test script). Generic component survives `Object.assign` — `<Menu.RadioGroup<T>>` JSX inference works.
- **base-ui `Autocomplete`**: collection registers ONLY via the `List` render-prop `{(item)=>...}` — a manual `.map` renders `role=option` but selection is DEAD. Selection is input-string oriented: arrives as `onValueChange(reason==="item-press")` carrying `itemToStringValue(item)` (set it to the **id** → collision-proof + touch-safe, no highlight-timing dep), NOT `onClick`. `mode="none"` = server-driven (no client filter); leave `open` uncontrolled (controlling it breaks dismissal + the Empty state).
- **xstate in a component**: hoist every user event to the machine top-level `on` (`reenter:true`) — every gesture valid in every state, no per-state dup, no swallowed events. Build the provided machine ONCE (`useMemo([])`) + read `port`/`onChange`/`geolocate` via refs — `@xstate/react` captures `provide()` closures at mount, so deps would be dead or reset state (ref, not `useEffectEvent` — actions run outside React's event context).
- **Odometer under SSR**: NumberFlow treats the first post-hydration update as initial render → the 0→N mount roll silently no-ops if triggered one rAF after hydrate (Storybook is client-only and masks this — ALWAYS verify odometer motion in the consuming app). Keep the padded 0→N roll (ADR-0054 F2) with an element-readiness trigger; `rollOnMount={false}` for SSR/SEO surfaces that must paint the true value.
- **Skeleton/loading animation** (native iOS/Notion/Linear): low-contrast soft-gray **opacity pulse** (0.5↔1, ~1.6s `cubic-bezier(0.4,0,0.6,1)`, slight per-row stagger), opacity-only (GPU). NEVER a high-contrast directional gradient sweep — reads robotic. `motion-reduce` → static. **Chart-skeleton exception (HITL 2026-07-07):** chart-shell content-shaped skeletons use the evilcharts shimmer — low-contrast bell-curve luminance band traveling ALONG the data shape via SVG pattern mask (floor 0.4 keeps shape legible; bar/line re-randomize geometry per loop on shimmer-exit). Shimmer along the shape ≠ slab sweep across a box; the ban still holds for boxy skeletons.
- Polymorphic primitives: base-ui `useRender` from `@base-ui/react` (`{render, props, defaultTagName}`) — the `render` slot on `Table.Row`/`Cell`. Module augmentation must be `interface` → prefix `// biome-ignore lint/style/useConsistentTypeDefinitions`.
- **base-ui `ScrollArea.Content`**: inline `min-width:fit-content` beats downstream `min-w-0` → nowrap child (long name) blows width, leaks page scroll. Fix: `.tbn-scroll-area__content{min-width:0 !important}` (pkg never uses horizontal scroll). Still need own `min-w-0` chain too (e.g. `.tbn-file-tile`).
- **DS is rounded, token-driven.** Job-portal Figma uses rounded corners throughout (inputs, buttons, chips, cards). Radius NEVER hardcoded in a component — consume `--radius-field` / `--radius-button` / `--radius-surface` / `--radius-popover` / `--radius-pill` from `tokens/radius.css`. Arbitrary `rounded-[Npx]` in a component is a review-blocking defect; a new radius need = new named token, HITL-approved.
- **ScrollArea `mask-image` fade = stacking context that CLIPS paint of ALL descendants — including `position:fixed` ones.** Full-screen surfaces rendered inside it (modals, overlays, floating pills) MUST `createPortal(document.body)`; no z-index escapes paint clipping.
- **R3F `<Canvas>` under an animated ancestor transform** (motion layout/scale) mis-sizes: react-use-measure reads gBCR (transform-affected) and ResizeObserver never re-fires for transforms → canvas freezes small. Fix: `resize={{ offsetSize: true }}` on the Canvas.
- **visx `ParentSize` (v4) wraps children in `position:absolute; inset:0; overflow:hidden`** — under an auto-height parent, `height:100%` collapses to 0 and the chart is PAINT-CLIPPED to nothing while gBCR/play-tests still report full sizes (DOM queries green, screen blank). Its parent MUST have explicit height (chart sizer div sets `style={{height}}`); charts keep a `getBoundingClientRect().height > 100` play assertion as the paint-level guard.
- **Soft edge glow = soft radial-gradient mask over the gradient** (`transparent X% → black Y%`). NEVER a clipping mask over `filter: blur` — the mask re-cuts a hard inner edge ("thick border" failure, edge-glow). Demo-frame px values don't transfer to full viewport; rescale.
- **Celebration motion doctrine**: hero celebration = `canvas-confetti` (catalog dep), lazy `import()` INSIDE the fire effect (~4kB loads only on celebrate; body-level canvas escapes ScrollArea paint-clip). Micro-bursts (≤60px travel) = hand-rolled WAAPI + per-particle size/duration variance (uniformity reads mechanical). **Celebration ∝ sentiment**: low/negative ratings get NO particles (StarRating 1-2★ = fill only); scale count/travel with value, peak-end reserved for max.
- canvas (2d/confetti/WebGL) colors: NEVER regex-parse `getComputedStyle` colors — modern browsers serialize `oklch()`/`color()`, not `rgb()`. Resolve `--tbn-*` → hex via probe element + 2d-context `fillStyle` roundtrip (returns `#rrggbb`; token chain holds through canvas).
- CSS-animation retrigger from a handler: remove data-attr → `el.getBoundingClientRect()` (forced reflow — `void el.offsetWidth` trips biome `noVoid`) → re-add attr.
- `ultracite fix` CSS property-sorting can DROP adjacent `/* @extrapolated */` / HITL comments — `grep @extrapolated` the file after any scoped fix and restore.
- Celebration gold = existing `--color-brand-yellow` (#FFCA00, also edge-glow/voice-persona) — grep `tokens/colors.css` before minting any new primitive.

## Chart suite (line/bar/donut/radar/radial/sankey/brush + chart-shell) — hardened 2026-07-07

- **Any chart work → use the `tribune-charts` skill** (anatomy, prop contract, motion constants, pitfall catalog, verification loop). Rules below are the law; the skill is the manual.

- Shared vocab lives in `chart-shell/`: `series.ts` (SeriesDatum/colors/format/`computeMaxWithHeadroom`) + `interaction.ts` (`useKeySelection`/`useEntered`/`activateKeyDown`/`resolveDimmed`). Never re-implement these per-chart.
- **API symmetry is law**: `keyFormat`/`valueFormat`, `hidden`, `dimmedKey`, `selectedKey`+`onSelectedKeyChange`, `onDatumSelect`, `ariaLabel`, `animate`, `glowing` — same name/shape on every applicable root. New chart = extend `SquareChartProps`(`size`) or `RectChartProps`(`height`). `onCursorChange(key: string|null)` on axis charts.
- **Two keyboard models by design** (don't unify): continuous-axis (bar/line) = one focusable svg `role="group"` + arrow-scrub + sr-only polite live region (keyboard-only announcements); discrete-shape (donut/radar/radial/sankey) = per-element `role="button"` tab stops via `activateKeyDown`. **Discrete-shape charts assemble from the `chart-shell` scaffold** — `useShapeChart`/`shapeInteractionProps` (`shape-chart.ts`), `ShapeDefs` (`shape-defs.tsx`), `ChartSrTable` (`sr-table.tsx`) — mandated, never hand-rolled per chart.
- **`colorVar()`/`--tbn-viz-cat-*` = blessed alias-law exception** — shared series palette consumed raw by design; every other viz token still re-aliases per component.
- **Motion doctrine**: springs via motion lib, NEVER hand-rolled rAF tweens. Data-truth morphs = critically damped (no overshoot; morph spring `380/40/1`, cursor `550/47/1`); overshoot (`--ease-spring`) reserved for entrances. Continuous pixel state (cursor/tooltip/drag) = motion values writing SVG attrs/CSS vars imperatively — never React state per frame. Direct-manipulation drag = `.jump()` (1:1), spring only on release/keyboard. EVERY JS-driven motion gates on `useReducedMotion()` (Tailwind `motion-reduce:` only covers CSS animations, not springs/transitions).
- Bar value morphs ride `transform: scaleY(var(--tbn-bar-scale))` (fill-box origin), never x/y/width/height attr transitions (reflow storm). d3-sankey throws on cyclic links — `breakCycles` guard in sankey frame is load-bearing (reopen flows produce cycles).
- Aggregate duplicate `dimensionKey` rows (sum), never `.find` first-match — bucketed SeriesDatum[] is valid input to every chart.
